Place finished or manually approved album recreation images in this folder.

Suggested file naming:
- `artist-name---album-title.png`
- `artist-name---album-title.jpg`

Examples:
- `michael-jackson---thriller.png`
- `radiohead---ok-computer.jpg`

This folder is intended to hold completed outputs you already made and want to
keep separate from the source covers in `to-process/`.
