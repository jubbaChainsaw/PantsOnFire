# Mobile Deployment Roadmap

## Goal

Deploy Pants On Fire to Google Play and Apple App Store using the existing Expo wrapper and RevenueCat integration.

## Phase 1 - Internal Testing

- Android internal testing.
- Test purchases.
- Entitlement validation.
- Crash testing.
- Device compatibility testing.

## Phase 2 - Closed Beta

### Google Play

- Create store listing.
- Complete Data Safety form.
- Privacy policy.
- Internal and closed testing tracks.

### Apple

- TestFlight rollout.
- App Store Connect setup.
- Privacy disclosures.
- Sign in with Apple review.

## Phase 3 - Release Readiness

- RevenueCat validation.
- Restore purchases.
- DLC unlock verification.
- Subscription verification.
- Online lobby load testing.

## Phase 4 - Public Launch

- Android production rollout.
- iOS production rollout.
- Monitoring and support.

## Required Services

- RevenueCat
- Supabase
- LiveKit
- Redis
- Hosting provider for lobby server
