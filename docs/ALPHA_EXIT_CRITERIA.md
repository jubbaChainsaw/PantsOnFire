# Alpha Exit Criteria

The game exits Alpha when all items below are complete.

## Content

- Persona artwork complete.
- Persona bios complete.
- Host artwork complete.
- Host voice packs complete.
- Theme assets complete.
- Core round types complete.

## Stability

- No critical gameplay bugs.
- No reveal leaks.
- No score corruption.
- No lobby corruption.
- No purchase-blocking issues.

## Playtesting

- Minimum 10 successful sessions.
- Minimum 50 rounds completed.
- Multiple player groups tested.
- Online lobbies tested.

## Mobile

- Android test build working.
- RevenueCat purchase validation tested.
- Entitlements tested.

## Online

- Reconnect handling tested.
- Lobby recovery tested.
- Voice rooms tested.
- Redis deployment tested.

## Documentation

- Deployment documentation available.
- Security model documented.
- Playtest findings documented.

Once all items are complete the project can move to closed beta testing.
