# Playtest Plan

## Current Goal

Validate gameplay clarity, pacing, replayability, host content, persona content and stability before wider beta testing.

## Test Groups

### Group 1
- Friends and family.
- Small local groups.

### Group 2
- Casual players unfamiliar with the rules.
- Observe without explaining gameplay.

### Group 3
- Online lobby testing.
- Voice testing.
- Reconnect testing.

## Metrics

Track:

- Time to first round.
- Time to understand rules.
- Number of confusing moments.
- Number of laughs.
- Session length.
- Most popular round types.
- Most popular themes.
- Bugs found.

## Content Validation

- Persona artwork complete.
- Persona bios complete.
- Host voice lines complete.
- Theme assets complete.
- Reveal sequences tested.

## Bug Severity

Critical:
- Game cannot continue.
- Reveal information leaks.
- Score corruption.
- Lobby corruption.

Major:
- Round flow confusion.
- Broken assets.
- Audio failures.

Minor:
- Cosmetic issues.
- Text improvements.
