Place source album cover images for the Nano Banana workflow in this folder.

Suggested file naming:
- `artist-name---album-title.jpg`
- `artist-name---album-title.png`

Examples:
- `michael-jackson---thriller.jpg`
- `radiohead---ok-computer.png`

This folder is intended to hold the original album cover files that will be
used as direct image inputs for the album recreation workflow.
