# Chewy (dialogue font)

Bundled for offline use in the Android APK and web build.

- **Family:** Chewy  
- **License:** [Apache License 2.0](LICENSE.txt) ([Google Fonts](https://fonts.google.com/specimen/Chewy))  
- **Source:** [google/fonts `apache/chewy`](https://github.com/google/fonts/tree/main/apache/chewy)  
- **Files:** `Chewy-Regular.ttf` (TTF for accurate tooling), `Chewy-Regular.woff2`, `Chewy-Regular.woff` (web bundles)  

App dialogue uses `--pof-dialogue-font-family: 'Chewy', cursive` in `src/pof-components.css`.
