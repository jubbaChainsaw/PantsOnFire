# Admin Tools

This folder contains development/admin-only tooling that is intentionally separated from the main game runtime code.

## Included

- `Pants-on-Fire-Card-Generator/`
  - Local-first React + TypeScript tool for card artwork prompt generation,
    round-structured text generation, and printable deck prep.

## Notes

- Treat this as a standalone tool workspace.
- It should not be bundled into the standard game runtime.
